# Uncertainty and clean spelling-cost execution specification

14 October2026. Implemented statistical/accounting primitives; tests prepared
for Kaggle, not run locally. No new outcome analysis performed.

Primary reporting counts every clean character, including genuine decoder
errors. Rejection is score strictly above clean threshold. Report observed FAR,
clean accuracy, accepted-correct and accepted-wrong rates with common original
character denominator, plus conditional accepted accuracy with its denominator.
If all characters are rejected, conditional accuracy is undefined, not zero or1.

Per-user intervals use two-sided95% exact binomial intervals, labeled IID
character descriptions, not guarantees under serial dependence. These differ
from previous one-sided95% zero-alarm feasibility bounds; never interchange.
Population paired effects use one summary per subject averaged across all
predeclared seeds, subject-paired2000-resample bootstrap seed20261013. Never
resample multiple attack targets as independent participants. Report subject
range and all seeds; do not infer individual assurance from population intervals.
Future cross-session analysis must cluster sessions within the same subject.

Retry overhead1/(1-observedFAR)-1 is a labeled ideal IID unchanged-retry
sensitivity, not measured delay or clinical throughput. At all rejected it is
undefined/unbounded. Actual cost should additionally report one observed
rejection count per recorded character and decision durations from recorded
markers, with the known physical-timing caveat. Corrective spelling/backspace
cost requires a separately frozen policy before claiming usable throughput.

No hypothesis-test p-value is generated by these primitives. If formal multiple
comparisons are later selected, freeze their family and correction before
independent outcomes, not post-hoc significant comparisons. Statistical code
supports reviewable evaluation, not a successful defense claim.
