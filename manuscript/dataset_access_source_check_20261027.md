## OpenBMI source locations

Original dataset identifier: DOI10.5524/100542, GigaDB record
https://gigadb.org/dataset/100542 . The provider endpoint was reached but returned
no extractable page text through the web tool. This does not establish its
current license text or absence of access terms.

Original article: Lee etal., EEG dataset and OpenBMI toolbox for three BCI
paradigms: an investigation into BCI illiteracy, DOI10.1093/gigascience/giz002,
https://academic.oup.com/gigascience/article/8/5/giz002/5304369 . The publisher
HTML and PDF retrieval redirected to an inaccessible publisher CDN. Do not treat
that retrieval failure as evidence of changed license or a verified ethics
statement. No signed CDN URL is retained here.

The official authors' toolbox repository
https://github.com/PatternRecognition/OpenBMI was readable. Its README identifies
MI, ERP and SSVEP examples, paradigm code including a P300 speller, a GigaScience
folder and the project website. This verifies an original implementation source
location, not that our exact transformed inputs or entire research package are
reproduced by downloading that toolbox. No code was imported or executed from it.

Search results also expose derivative collections with differing software/data
license labels. They were not used as authority for raw-data redistribution or
for the original participants' ethics approval. Distinguish toolbox software,
article license, original dataset record and third-party derivative licenses.
Do not copy a derivative's GPL or CC0 label into our final availability statement
without the actual upstream dataset terms.

## Consequence for final package

The current draft correctly directs users to the original provider and retains
redistribution/ethics verification as unresolved. Final manuscript availability
should cite both the article and dataset identifier, specify the exact session1
ERP/P300 acquisition and immutable input hashes, and separate our derived outputs
and own code from upstream content. Reviewer access to our private exact artifact
set still needs to be arranged; the existence of public upstream data does not
provide access to our private models, scores, receipts or figures.

No public release, new sharing permission, ethics exemption or IRB approval for
the present author is asserted by this check. The author must confirm applicable
institutional requirements. The source-retrieval limitation is recorded rather
than replaced by a third-party license assumption.
